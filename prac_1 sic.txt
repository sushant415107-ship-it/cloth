# 6️⃣ Extended Numbered ACL

### Requirement

* **PC1 → FTP only**
* **PC2 → Web only**
* **PC1 and PC2 cannot communicate with each other**

---

## Step 1: Create ACL

```bash
access-list 100 permit tcp 172.22.34.64 0.0.0.31 host 172.22.34.62 eq ftp
```

---

### Allow ICMP

```bash
access-list 100 permit icmp any any
```

---

### Allow Web Access from PC2

```bash
access-list 100 permit tcp 172.22.34.96 0.0.0.15 host 172.22.34.62 eq www
```

---

### Deny Communication Between PCs

```bash
access-list 100 deny ip 172.22.34.64 0.0.0.31 172.22.34.96 0.0.0.15
```

---

### Permit Remaining Traffic

```bash
access-list 100 permit ip any any
```

---

# 7️⃣ Apply ACL to Router

Apply on **G0/2 inbound**

```bash
interface g0/2
ip access-group 100 in
```

---

# 8️⃣ Named ACL Configuration

Remove old ACL

```bash
no access-list 100
```

---

Create Named ACL

```bash
ip access-list extended SERVER-ACCESS
```

---

### FTP for PC1

```bash
permit tcp 172.22.34.64 0.0.0.31 host 172.22.34.62 eq ftp
```

---

### Web for PC2

```bash
permit tcp 172.22.34.96 0.0.0.15 host 172.22.34.62 eq www
```

---

### Deny PC Communication

```bash
deny ip 172.22.34.64 0.0.0.31 172.22.34.96 0.0.0.15
```

---

### Allow Other Traffic

```bash
permit ip any any
exit
```

---

### Apply Named ACL

```bash
interface g0/2
ip access-group SERVER-ACCESS in
```

# 6️⃣ IPv6 ACL 1 (Block HTTP & HTTPS)

Configure on **R1**

```
ipv6 access-list BLOCK_HTTP
```

Block HTTP

```
deny tcp any host 2001:DB8:1:30::30 eq www
```

Block HTTPS

```
deny tcp any host 2001:DB8:1:30::30 eq 443
```

Allow other traffic

```
permit ipv6 any any
```

---

### Apply ACL

```
interface g0/1
ipv6 traffic-filter BLOCK_HTTP in
```

---

# 7️⃣ IPv6 ACL 2 (Block ICMP)

Configure on **R3**

```
ipv6 access-list BLOCK_ICMP
```

Block ping

```
deny icmp any any
```

Allow other traffic

```
permit ipv6 any any
```

---

### Apply ACL

```
interface g0/0
ipv6 traffic-filter BLOCK_ICMP out
```
